# 🔐 Java Password Manager (CLI)

A simple command-line 📋 Password Manager written in Java. This project allows users to store app login credentials securely in memory and persist them to a local text file. Designed to reinforce core Java concepts such as object-oriented programming, file I/O, and data structures.

---

## 🚀 Features

- ➕ Add multiple password entries (App, Username, Password)
- 🗃 Store entries as objects using a custom class (`PasswordEntry`)
- 💾 Automatically saves entries to `passwords.txt`
- 📚 Clean output formatting and user prompts
- ✅ Lightweight, menu-driven, and beginner-friendly

---

## 🧠 Technologies Used

- 💻 Java (JDK 8+)
- ✍️ `Scanner` for user input
- 🧱 `ArrayList` for in-memory storage
- 🗃 `FileWriter` for saving to file
- 🎯 Command-Line Interface (CLI)
